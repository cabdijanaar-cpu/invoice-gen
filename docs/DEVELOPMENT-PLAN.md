# InvoiceFlow – qorshaha horumarinta

**La cusboonaysiiyey:** 2026-10-18  
**Xaalad:** Horumarin socota  
**Xogta asalka ah:** Eeg [PROJECT.md](PROJECT.md), [ROADMAP.md](ROADMAP.md), [DATABASE.md](DATABASE.md), iyo [SECURITY-DEPLOYMENT.md](SECURITY-DEPLOYMENT.md).

Qorshahani wuxuu sii dhisayaa app-ka hadda jira. Waxa uu ilaalinayaa Next.js App Router, Prisma, Supabase PostgreSQL, authentication-ka, tenant isolation-ka, iyo xisaabaadka ganacsi ee jira. Bog ama feature waxaa loo calaamadinayaa “la xaqiijiyey” marka caddaynta hubintiisa la qoro.

## Xaaladda hadda

- Core-ka ganacsiga waa jiraa: dukaamo badan, dashboard, customers, inventory, invoices, quotations, payments/debts, expenses, reports, staff, settings, subscriptions iyo platform admin.
- Isbeddelladii UI-ga ee workspace-kan waxay hagaajiyeen invoice/quotation forms iyo muuqaalka guud. Shop shell-ku wuxuu leeyahay sidebar desktop, mobile menu la furo/xiro, shop switcher ku salaysan active memberships, shop-ka firfircoon iyo role-ka user-ka. Liiska wuxuu ku xaddidan yahay modules-ka jira, staff iyo subscription-na role ayaa xakameeya. Tobanka bog ee workspace-ka ee waaweyn waxay wadaagaan page header, content width iyo spacing. Invoice editor-ku wuxuu leeyahay live invoice preview dhinaca midig ee desktop-ka iyo hoosta foomka ee shaashadaha yaryar; xeerarka xisaabinta lama beddelin. Dashboard-ku wuxuu leeyahay sales trend billaha ah oo range date lagu sifeeyo, waxaana query-gu ku xiran yahay `shopId` iyo finalized invoice status.
- Bogga Payments & Debts wuxuu muujinayaa lacagaha la diiwaangeliyey ee date range-ka, balances-ka guud, iyo balances-ka 100-kii invoice ee ugu dambeeyey. Payment history-gu wuxuu ku kooban yahay 100 record; narrowing date range ayaa kala shaandheeya. Search-ka guud iyo notifications weli waa shaqo qorshaysan.
- Hubin read-only oo authenticated ah ayaa 11-ka shop route ku maray 391px iyo 1440px CSS viewport; dhammaantood way furmeen oo horizontal overflow ma jirin. Keyboard focus-ka desktop-ka iyo menu/navigation-ka mobile-ka waa la hubiyey. SHOP_OWNER iyo CASHIER roles, laba shop oo la kala beddelay, iyo restricted settings/reports/subscription direct routes waa la xaqiijiyey. MANAGER, owner, iyo cashier roles waa la hubiyey; invoice draft/finalize, partial payment, iyo expense form waa la mariyey xog synthetic ah. Permission-ka reports/settings/staff/subscription waa la diiday si cad. Production deployment iyo email delivery weli lama xaqiijin.

## Habka fulinta

1. Ka hor isbeddel kasta, eeg `git status`, handoff-ka `PROJECT.md`, route-ka iyo server action-ka la taabanayo. Ha tirtirin ama dib ha uga qorin shaqo hore u jirtay.
2. Akhri hagaha ku habboon ee `node_modules/next/dist/docs/` marka la beddelayo Next.js API ama convention; Next.js 16 ayaa mashruuca ku rakiban.
3. Isbeddel kasta ku koob hal meel oo la review-gareyn karo. Xaqiiji server authorization iyo tenant scope ka hor inta aan UI-gu muujin ama qorin xog.
4. Lacagta, stock-ga, payment/refund iyo invoice lifecycle-ka ha la beddelin ilaa domain code, policy-ga `DATABASE.md`, iyo tijaabooyinka jira la wada eego.
5. Kadib milestone, ku qor `PROJECT.md` files-ka la beddelay, checks-ka dhab ahaan la fuliyey, natiijada, iyo waxyaabaha furan. Isku waafaji `ROADMAP.md` iyo qorshahan.

## Hubinta iyo ka bixitaanka

Marka UI milestone la dhammaystiro, samee lint, TypeScript check iyo production build. Tijaabooyinka jira ee khuseeya business logic-ka waa in la ordiyaa marka logic-gaas is beddelo. Browser-ka ku hubi desktop iyo mobile: navigation, page load, form submit, empty/error, focus/keyboard, iyo role kala duwan haddii browser iyo credentials la heli karo. Haddii hubin la waayo, ku qor “lama xaqiijin” oo ha u calaamadin Verified.

Release kasta ka hor, xaqiiji migrations-ka database-ka saxda ah, secrets-ka server-ka oo keliya, shop isolation, invoice totals/stock, PDF/CSV, session/security settings, cron, email iyo backup/restore. Deployment ama beddel infrastructure ah looma tixgelinayo mid dhammaystiran ilaa deegaan production lagu hubiyo.
